# ---- Go runtime base (gowebapp Dockerfile runtime stage) ----
# distroless static + nonroot: no shell, no package manager, uid 65532 — the app is a static
# CGO_ENABLED=0 binary, so nothing else is needed in the image.
# `nonroot` is a MOVING tag (like `latest`) — distroless publishes no semver tags, so the tag alone

# digest pin), and the mirror handles the `repo:tag@digest` shape (lib/mirror.sh:12).
# renovate: datasource=docker depName=gcr.io/distroless/static-debian12
